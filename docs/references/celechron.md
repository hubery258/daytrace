## Celechron 课表/成绩/学分 实现全解析

这是一个浙大学生数据聚合 Flutter App，通过**爬虫抓取**多个校内系统来展示课表、成绩、GPA。下面是完整的技术架构分析：

---

### 一、认证系统（SSO 登录链）

核心文件：zjuam.dart → `ZjuAm.getSsoCookie()`

| 步骤 | 动作 | 关键点 |
|------|------|--------|
| 1 | GET `zjuam.zju.edu.cn/cas/login` | 从 HTML 中提取 `execution` token |
| 2 | GET `zjuam.zju.edu.cn/cas/v2/getPubKey` | 获取 RSA 公钥（`modulus` + `exponent`，16进制） |
| 3 | RSA 加密密码 | 密码 UTF-8 → hex → `BigInt` → `modPow(exponent, modulus)` → 128位 hex |
| 4 | POST `/cas/login` | `username` + 加密 `password` + `execution` + `_eventId=submit` |
| 5 | 提取 Cookie | 返回 `iPlanetDirectoryPro` → **SSO 主Cookie** |

拿到 `iPlanetDirectoryPro` 后，用它分别换取各个子系统的认证：

| 子系统 | 服务类 | 认证方式 |
|--------|--------|----------|
| 教务网 (ZDBK) | `Zdbk` | CAS 重定向 → 拿到 `JSESSIONID` + `route` Cookie |
| 研究生院 (GRS) | `GrsNew` | CAS 重定向 → 拿到 `ticket` → 调用 `/validateLogin` → 拿到 `X-Access-Token` |
| 学在浙大 (Courses) | `Courses` | CAS 重定向 → 拿到 `session` Cookie |

### 二、课表查询（两种实现）

#### 2.1 本科生课表 — `Zdbk.getTimetable()`

**文件**：zdbk.dart

```
POST https://zdbk.zju.edu.cn/jwglxt/kbcx/xskbcx_cxXsKb.html
Headers: Cookie(JSESSIONID + route), X-Requested-With=XMLHttpRequest
Body:   xnm=2024&xqm=3&captcha_value=xxx
```

- 参数：`xnm`=学年, `xqm`=学期码（`1|秋`, `1|冬` → 秋冬学期=3; `2|春`, `2|夏` → 春夏学期=12）
- 返回 JSON 中的 `kbList` 数组
- 有验证码机制：如果返回 `captcha_error`，则 GET `/jwglxt/kaptcha` 获取验证码图片弹窗让用户输入

**Session 解析**（`Session.fromZdbk()`）：
```dart
dayOfWeek = int.parse(json['xqj'])       // 星期几 1-7
oddWeek = (dsz != '1')                    // 单周上课
evenWeek = (dsz != '0')                   // 双周上课
time = List<int>.generate(skcd, (i) => djj + i)  // 起始节次+持续节数
// kcb 字段是 HTML: "课程名<br>教师<br>地点<br>zwf"
name/teacher/location = 正则提取
// xxq 字段判断 秋/春(firstHalf) 冬/夏(secondHalf)
```

#### 2.2 研究生课表 — `GrsNew.getTimetable()`

**文件**：grs_new.dart

```
GET https://yjsy.zju.edu.cn/dataapi/py/pyKcbj/queryXskbByLoginUser?xn=2024&pkxq=13
Header: X-Access-Token: xxx
```

- 学期码：`13`=秋冬上半, `14`=秋冬全年, `11`=春夏下半, `12`=春夏全年
- 返回结构：`result.kcbMap[dayOfWeek][period].pyKcbjSjddVOList`
- 按 `bjbh`(班级编号) 合并连续节次，用 `zc`(周次) 获取 `customRepeatWeeks`

### 三、成绩查询（两种实现）

#### 3.1 本科生成绩 — `Zdbk.getTranscript()`

```
POST https://zdbk.zju.edu.cn/jwglxt/cxdy/xscjcx_cxXscjIndex.html?doType=query&queryModel.showCount=5000
```

返回 JSON，用正则 `(?<="items":)\[(.*?)\](?=,"limit")` 提取成绩数组。

**Grade 模型**（grade.dart）：

| 字段 | 来源 | 说明 |
|------|------|------|
| `id` | `json['xkkh']` | 选课课号 |
| `name` | `json['kcmc']` | 课程名（括号统一转中文） |
| `credit` | `json['xf']` | 学分 |
| `original` | `json['cj']` | 原始成绩（"95"/"A+"/"优秀"/"合格"等） |
| `fivePoint` | `json['jd']` | 五分制绩点 |

**成绩换算表**（`_toHundredPoint`）：
- 字母等级：`A+→95, A→90, A-→87, B+→83, B→80, B-→77, C+→73, C→70, C-→67, D→60, F→0`
- 中文等级：`优秀→90, 良好→80, 中等→70, 及格→60, 不及格→0`
- 特殊：`合格→75, 不合格→0, 弃修→0, 缺考→0, 缓考→0`

**四分制转换**：`5.0→4.3, 4.8→4.2, 4.5→4.1, 4.2→4.0`，原四分制直接截断到 4.0

**是否计入GPA**：排除"弃修/待录/缓考/无效/合格/不合格/通识外课程(xtwkc)"

#### 3.2 研究生成绩 — `GrsNew.getGrade()`

```
POST https://yjsy.zju.edu.cn/dataapi/py/pyXsxk/queryXsxkByXnxqXs
Header: X-Access-Token: xxx
```

返回 `result.xxjhnList`，跳过 `xkztMc=="未处理"` 的条目。从 `sjddBz` 提取班级编号，`zf` 取综合分（百分制）。

#### 3.3 主修成绩（本科生）— `Zdbk.getMajorGrade()`

```
POST https://zdbk.zju.edu.cn/jwglxt/zycjtj/xszgkc_cxXsZgkcIndex.html?doType=query&queryModel.showCount=5000
```

返回结构与普通成绩相同，但所有成绩标记 `major=true`。

### 四、学分与 GPA 计算

核心文件：gpa_helper.dart

#### 4.1 标准 GPA 计算

```dart
GpaHelper.calculateGpa(Iterable<Grade> grades)
```

公式：
$$\text{加权和} = \sum (\text{绩点} \times \text{学分}) \quad (\text{仅计入GPA的科目})$$
$$\text{GPA} = \frac{\text{加权和}}{\text{计入GPA的总学分}}$$

返回 4 个维度的 GPA：`[五分制, 四分制(4.3满分), 原始四分制(4.0满分), 百分制均分]`

#### 4.2 学时学分

```dart
earnedCredits = Σ grade.earnedCredit
// earnedCredit = creditIncluded && (fivePoint > 0 || 通识外课程) ? credit : 0
```

#### 4.3 保研 vs 出国 GPA（`Scholar.refresh()`）

```dart
// 保研GPA：每门课只取第一次成绩
gpa = GpaHelper.calculateGpa(grades.values.map((e) => e.first));

// 出国GPA：每门课取百分制最高分那次
aboardGpa = GpaHelper.calculateGpa(grades.values.map((e) => e.sortedBy(hundredPoint).last));
```

课程去重逻辑：解析课号ID `(学期)-课程编码-选课序号`，按课程编码分组。体育课（`PPAE`/`401`）特殊处理。

#### 4.4 加权 GPA

`GpaHelper.calculateWeightedGpa(grades, weightMap)`：绩点直接乘以加权比例，再按原学分加权平均。

#### 4.5 实践学分（二三四课堂分）

```
GET https://zdbk.zju.edu.cn/jwglxt/dessktgl/dessktcx_cxDessktcxIndex.html?su=学号
```

解析 HTML 表格用正则提取 第二/三/四课堂分数。

### 八. 校历抓取

#### 校历来源

Celechron **独立维护了一套校历数据**，托管在自建 CDN 上：

```
http://calendar.celechron.top/{学年}-{学年+1}-{学期}.json
```

命名规则：

| 学期 | URL 示例 | 说明 |
|------|----------|------|
| 秋冬学期 | `calendar.celechron.top/2024-2025-1.json` | `-1` 第一学期 |
| 春夏学期 | `calendar.celechron.top/2024-2025-2.json` | `-2` 第二学期 |

#### JSON 结构

```json
{
    "sessionTime": [
        [],                           // index 0 占位
        ["08:00", "08:45"],           // 第1节 开始-结束
        ["08:50", "09:35"],           // 第2节
        // ... 共16节课
        ["22:10", "22:55"]            // 第16节
    ],
    "startEnd": [
        "20240909",                   // 上半学期开始日 (秋冬学期=秋)
        "20241103",                   // 上半学期结束日
        "20241104",                   // 下半学期开始日 (秋冬学期=冬)
        "20241229"                    // 下半学期结束日
    ],
    "holiday": {
        "20241001": "国庆节"           // 真实法定假日
    },
    "dummy": {
        "20240915": "中秋节"           // 补休/周末放假（不上课但不调课）
    },
    "exchange": {
        "2024091620240914": "中秋节"   // 9月16日上9月14日(周六)的课
    }
}
```

#### 校历与课程数据的协作

```
ZDBK课程数据                    校历CDN
├─ 星期几 (dayOfWeek)           ├─ 学期起止日期 (startEnd)
├─ 第几节 (djj + skcd)     +    ├─ 节次时间映射 (sessionTime)
├─ 单/双周 (dsz)                ├─ 放假日期 (holiday/dummy)
└─ 秋/春/冬/夏 (xxq)            └─ 调休映射 (exchange)
        │                              │
        └──────────┬───────────────────┘
                   ▼
           Semester.addZjuCalendar()
                   │
         _dayOfWeekToDays[半学期][单双周][星期几] = [具体日期列表]
                   │
                   ▼
           Period (带绝对时间的日历事件)
           ├─ startTime = 日期 + sessionTime[节次].first
           ├─ 删除假期日的 Period
           └─ 调休日偏移 Period 日期
```

关键点：**课程数据只有相对位置（周几、第几节、单双周），校历提供绝对时间框架（日期映射、节次时分、假期调休），两者缺一不可。**

#### 对外可用性

该 CDN **对外开放、无需认证**，用 HTTP GET 即可获取。实测 2023-2026 的 JSON 均能正常访问。根目录返回 403，但只要知道 URL 格式就能直接命中文件。

#### 使用建议

1. **不要硬依赖**：这是个人维护的 CDN，无 SLA，随时可能不可用。必须做**本地缓存降级**——先尝试拉取，失败则用本地缓存，缓存也没有才报错。

2. **直接内置更稳妥**：校历数据每年仅两个文件、结构极其稳定（`sessionTime` 基本万年不变），建议直接把 JSON 放进项目仓库作为静态资源，只在每年更新 `startEnd` 和 `holiday/exchange`，彻底消除外部依赖。

3. **注意 HTTP 明文传输**：CDN 走的是 `http://` 而非 `https://`，存在中间人篡改风险。如果内置到项目中则可规避此问题。

4. **命名规则**：URL 拼接规则为 `{year}-{year+1}-{semester}.json`，`semester` 秋冬=1、春夏=2，无需遍历目录。

5. **`exchange` 字段解析**：key 格式为 `"YYYYMMDDYYYYMMDD"`，前8位是实际上课日，后8位是被替换的日期。需要做双向映射。
