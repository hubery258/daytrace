# v0.10 旧 JSON 清洗与导入

v0.10 的计划日程继续使用 schedules，实际记录使用 time_blocks。旧版 is_planned=false 的实际日程不会转换成时间块，也不会显示在新版日程页。新版导入器会自动跳过这部分；项目、待办、is_planned=true 的计划日程、日志、模板和计时会话仍可导入。

建议先在旧版设置页导出 JSON，另存一份原始备份。若想在导入前得到一份可检查的清洗文件，在仓库根目录运行：

    python scripts/clean-v010-legacy-json.py D:\backup\riji-old.json D:\backup\riji-v010-clean.json

脚本不会修改源文件；输出仍是 schema_version: 0.6.0，新版 Web/桌面/Android 均接受。它删除旧实际日程及对应旧实际重复规则，并清空计时会话中指向被删日程的 created_schedule_uuid。然后在新版设置页选择清洗后的 JSON，查看预览数量，再合并导入。ZJU 导入的课程属于计划日程，仍会保留在计划侧。

新版导出的 JSON 使用 schema_version: 0.10.0，新增 time_block_categories 和 time_blocks。切换设备时使用新版备份即可迁移时间块及其属性。计时记录本身会保留，但旧计时生成的实际日程不会自动折算为时间块。
