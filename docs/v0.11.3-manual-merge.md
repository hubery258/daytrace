# v0.11.3 手动设备数据合并

本地 SQLite、离线优先；JSON 文件和 WebDAV 下载共用预览与确认流程。WebDAV 只传输文件，保留 ETag 条件上传和远端变更保护。

## 合并规则

- UUID 识别实体，日志按日期；双方独有记录保留，缺少记录不传播删除，相同内容跳过。
- 任务完成优先。两边都完成时取较早有效完成时间，完成日志按任务身份去重到对应日期。无法确定日期时要求选择。名称、DDL、项目、备注等逐字段选择，空白也有效；备注可以人工整理。
- 实际时间块去重后仅选择重叠冲突区间，保留双方不冲突部分；拆分保持备注、关联、来源及原记录 UUID 标记。移动或修改同 UUID 需要明确选择，不复制两个版本。保持 15/30 分钟粒度和现有按占用分钟统计口径。
- 计划日程整条选择，不同 UUID 允许重叠。项目、属性、重复规则及例外、模板和同 UUID 计时记录也整条选择。
- 日志正文人工选择或整理，不自动拼接。重复导入不会自动追加正文。
- 同名不同 UUID 属性保留身份，要求重命名解决唯一名称限制。
- 多条活动计时要求选一条继续，其余保存为暂存暂停，之后可在没有当前计时时继续。
- 新包的重复计划模板关联任务使用 UUID；旧包仅含源设备整数任务编号时，预览要求重新选择任务，也可明确确认无关联，不猜测映射。

## 预览与执行

并排显示本机与导入值，逐项选择；批量选择限当前冲突范围，重命名、完成日期、活动计时和旧包关联仍需专门确认。预览展示真实新增、变更、相同跳过、冲突及删除/拆分影响。未解决冲突禁止执行。

执行 token 绑定数据包、选择和本地数据；正式执行在事务中重新读取并校验，过期要求重新预览。切换合并/恢复保留文件并重新预览。写入前保存操作前 JSON 副本，电脑端刷盘并读回校验，Android 使用原生文件插件写入并读回校验；副本不能确认成功时阻止操作。电脑副本位于数据库目录的 operation-backups，Android 位于 Documents/日迹。

恢复备份独立处理，允许恢复未完成状态；JSON 不导出凭据，两种操作均保留本机 WebDAV 配置和密码。响应丢失时不声称已回滚，提示重新检查本机数据。

## 使用与限制

两台设备均应升级 v0.11.3。合并后上传结果，再让另一台设备导入，才能带回汇总结果。合并不传播取消完成，也不传播删除；没有字段修改历史时，重复导入旧差异仍可能需要再次确认。

未引入账号、自动同步、后台队列或修改历史系统。尚未验证实体 Android 设备的原生文件读写、UI 操作、安装升级和真实 WebDAV 网络环境；自动测试不能替代这些检查。Android 产物为 debug APK，Windows portable 未提供正式签名。
