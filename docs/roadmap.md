# 项目状态与路线图

## 当前状态

v0.8 Android 功能对齐已完成代码与自动化验证阶段。Android 继续使用设备内 SQLite，不连接桌面 FastAPI，也不内嵌 Python；65 条业务能力均有显式契约，正常功能不再返回空成功。

已验证：前端 49 项测试、后端 22 项测试、Vite 构建、Capacitor 同步、Android 原生单测、lint（0 error）与 Debug APK 构建。Debug 产物见 `release/android/riji-android-0.8.0-debug.apk`。

尚未完成 M4 发布门槛：当前没有连接实体设备，未执行低版本/当前版本双机矩阵；仓库也没有用户的 release 签名凭据，因此不会生成或冒充签名 release APK。

外部限制：`calendar.celechron.top` 当前 HTTPS 不可用。Android 不降级到明文 HTTP，校历实时刷新明确失败，精确缓存读取仍可用。详见 `docs/v0.8-android-acceptance.md`。

v1.0.0 的目标不是做账号同步版，而是发布一个无需账号、无需同步、可以长期本地使用的正式单机版。

### v0.3.x：日程体验与计时

### v0.4.x：AI 草稿助手与复盘流程

状态：已完成。详细设计已归档到 `docs/archive/v0.4-ai-assistant.md`。

### v0.5.x：重复任务与重复日程

状态：已完成。详细设计已归档到 `docs/archive/v0.5-recurrence.md`。

### v0.6.x：安卓端与桌面端打包体验版 + 基础导入导出

状态：已完成。详细设计与构建说明已归档到 `docs/archive/v0.6-packaging.md`。Electron portable 和 Android debug APK 已产出，双向 JSON 迁移已验证。

目标：同时尝试安卓端和桌面端打包，并加入基础数据导入导出，让日迹从浏览器应用过渡到更接近正式产品的使用形态。

边界：

- v1.0 前仍不做账号同步。
- 安卓端和桌面端可以先接受独立本地数据。
- 优先验证打包、启动、数据本地存储、基础页面适配和核心流程可用。
- 提供基础 JSON 导入导出，用于在电脑、安卓、桌面端之间手动迁移数据并验证未来同步模型。
- 不在 v0.6.x 追求完整系统级提醒。

### v0.7.x：UI、交互与品牌感升级

状态：已完成。实现与验收记录见 `docs/archive/v0.7-ui-brand.md`。

目标：摆脱当前临时 UI 的雷同感，让日迹形成更稳定、更有品格的视觉和交互语言，同时允许用户按自己的需要裁剪页面和模块。

说明：v0.7 做整体升级，但不改变产品主流程，也不把范围扩展到同步、提醒或复杂主题市场。这个版本最重要的是让用户一打开就感到“这是日迹”，而不是一套临时拼起来的管理后台。

建议包含：

- 形成日迹自己的视觉关键词：安静、清晰、日常感、计划与现实并置、本地可信赖。
- 统一全局导航、首页信息密度、日程时间轴、待办卡片、项目卡片、表单弹窗和设置页布局。
- 加入产品 Logo、桌面端图标、Android 图标和基础启动/空状态品牌元素。
- 设置页支持控制导航中展示哪些页面，例如非 ZJU 学生可以隐藏 ZJU 页面。
- 设置页支持控制首页和页面内模块展示情况，例如关闭首页项目模块。
- 页面开关不删除数据，只影响入口和展示。
### v0.8.x：Android 功能全量对齐

目标：把 Android 从核心功能体验版升级为功能完整的本地单机版，使 Windows/Web 可用的项目、待办、日程、重复规则、计时、总结、模板、AI、ZJU 和备份恢复流程均能在手机上独立完成。

应包含：

- Android 重复规则的创建、编辑、删除、生成、实例例外和批量同步。
- 项目、待办、日程的校验、排序、冲突检测和事务语义对齐。
- 计时在应用后台、系统回收和重启后的可靠恢复。
- Android 原生网络适配与安全凭据存储，激活 ZJU DDL、课表、校历和成绩功能。
- AI 请求、文件选择、备份恢复和错误处理的实机收尾。
- 双适配器契约测试、数据库版本迁移和跨端 JSON 互导验证。

详细计划见 `docs/v0.8-mobile-feature-parity.md`。

边界：v0.8 不做账号同步、自动云备份、后台同步队列或学校系统写操作。
### v0.9.x：稳定性、测试、文档和试用反馈收敛

目标：为 v1.0.0 做发布候选准备。

应包含：

- 完整手动冒烟测试清单。
- 关键功能回归测试。
- Web、桌面端、Android 三端核心流程检查。
- README 和 docs 更新。
- 试用反馈整理。
- 明确 v1.0.0 不做事项。

边界：v0.9 主要修稳定性和体验问题，不再主动增加大型新功能。
### v1.0.0：正式单机版

发布定义：

> 一个无需账号、无需同步、可以长期本地使用的个人效率工具正式版。

发布前必须确认：

- 核心数据可靠。
- 备份和导入导出可用。
- 主要功能经过连续自用验证。
- 关键错误有可理解的提示。
- 文档能帮助未来继续维护。
- v1.0.0 范围稳定，不把账号同步、系统级提醒或复杂平台能力塞进正式发布前。

### v1.1.x：账号与多端同步

v1.1.x 开始处理账号、同步和多设备一致性问题。

### v1.2.x：系统级提醒与通知

提醒功能放到正式版之后，并基于安卓端/桌面端/同步能力重新设计。

目标：

- DDL 临近提醒。
- 计划日程临近提醒。
- 每日自律提醒。
- 安卓和桌面系统通知。

### v1.3.x：每日内容与轻量个性化

在正式单机版稳定后，再考虑增强每天打开日迹时的仪式感，不把它扩展成复杂主题或内容市场。

可探索：

- 首页“每日一句”支持读取用户自行维护的 CDN 静态句库，例如按日期返回一句短文案。
- 每日首次打开时刷新并缓存当天内容，同一天保持稳定，不因重复进入首页频繁变化。
- 应用内保留默认句库和离线回退；CDN 不可用时不影响首页与其他核心能力。
- 远端只提供公开文案，不上传待办、日程、日志或设备信息。
- 提供明确的关闭与恢复默认选项，保持本地优先和低干扰原则。

边界：该方向只做轻量内容个性化，不进入主题市场、皮肤系统或插件市场。

## 暂缓事项

- v1.0.0 前不做账号和多设备同步。
- v1.0.0 前不做系统级提醒。
- 自动云备份、后台同步队列和冲突解决放到 v1.1 账号同步之后。
- DDL、日程、每日提醒、桌面/Android 系统通知放到 v1.2 系统级提醒之后。
- AI 直接越过用户确认创建或修改日程。
- 通用脚本市场。
- 自动签到、刷课、答题、提交等学校系统写操作。
- 看板、甘特图、多层级项目、复杂 RRULE、主题市场和插件市场不进入 v1.0 范围。
