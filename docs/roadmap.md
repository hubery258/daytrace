# 项目状态与路线图

## 当前状态

当前项目已经完成 v0.5.x：个人效率工具主流程可用，ZJU 只读集成第一阶段完成，项目、日程计时、AI 草稿助手、复盘能力、重复任务和重复日程已经加入。

v0.6.x 是下一阶段开发重点，目标是尝试安卓端与桌面端打包体验版，并加入基础 JSON 导入导出，为未来同步做数据模型验证。

## 已完成

- 待办创建、编辑、删除和完成。
- DDL 类型、提醒天数、临近 DDL 计算。
- 等待答复和关注任务。
- 首页核心面板。
- 计划日程和实际记录。
- 日程页共轴对照布局。
- 日程拖拽创建。
- 计时页和计时生成实际日程。
- 重复任务和重复日程。
- 今日总结、日志和日志模板。

- Docker Compose 长期自用模式和开发模式。
- ZJU 学习任务导入。
- ZJU 课表导入计划日程。
- ZJU 成绩与学分概览。
- 项目功能：待办和日程可以归入项目，用于承载更大的任务或目标。

## v0.6.x 当前开发重点

详细设计见 `docs/v0.6-packaging.md`。

v0.6.x 聚焦安卓端与桌面端打包体验版，以及基础 JSON 导入导出：

- v0.6.0：确定桌面端和安卓端技术路线，完成最小打包原型。
- v0.6.1：桌面端体验版。
- v0.6.2：安卓端体验版。
- v0.6.3：基础 JSON 导入导出。
- v0.6.4：跨端构建、数据目录和发布说明。

v0.6.x 不做账号同步，也不追求完整系统级提醒。

## v1.0 前版本路线

v1.0.0 的目标不是做账号同步版，而是发布一个无需账号、无需同步、可以长期本地使用的正式单机版。

### v0.2.x：项目功能

状态：已完成。详细设计已归档到 `docs/archive/v0.2-projects.md`。

### v0.3.x：日程体验与计时

状态：已完成。详细设计已归档到 `docs/archive/v0.3-schedule-timer.md`。

### v0.4.x：AI 草稿助手与复盘流程

状态：已完成。详细设计已归档到 `docs/archive/v0.4-ai-assistant.md`。

### v0.5.x：重复任务与重复日程

状态：已完成。详细设计已归档到 `docs/archive/v0.5-recurrence.md`。

### v0.6.x：安卓端与桌面端打包体验版 + 基础导入导出

Status: Experience build completed. Electron portable and Android debug APK were produced, and bidirectional JSON migration was verified.

目标：同时尝试安卓端和桌面端打包，并加入基础数据导入导出，让日迹从浏览器应用过渡到更接近正式产品的使用形态。

边界：

- v1.0 前仍不做账号同步。
- 安卓端和桌面端可以先接受独立本地数据。
- 优先验证打包、启动、数据本地存储、基础页面适配和核心流程可用。
- 提供基础 JSON 导入导出，用于在电脑、安卓、桌面端之间手动迁移数据并验证未来同步模型。
- 不在 v0.6.x 追求完整系统级提醒。

### v0.7.x：UI、交互与品牌感升级

目标：摆脱当前临时 UI 的雷同感，让日迹形成更稳定、更有品格的视觉和交互语言，同时允许用户按自己的需要裁剪页面和模块。

说明：v0.7 做整体升级，但从 v0.2 开始就应尽量保持基础设计原则一致，避免后期一次性重做成本过高。

建议包含：

- 设置页支持控制导航中展示哪些页面，例如非 ZJU 学生可以隐藏 ZJU 页面。
- 设置页支持控制首页和页面内模块展示情况，例如关闭首页项目模块。
- 页面开关不删除数据，只影响入口和展示。

### v0.8.x：正式级数据备份、恢复与升级兼容

目标：在 v0.6 基础导入导出的基础上，让单机正式版具备更完整的数据安全、恢复和升级兼容能力。

应包含：

- 更完整的数据导出。
- 更完整的数据导入。
- SQLite 备份说明或一键备份。
- 版本升级时的数据兼容检查。
- 关键数据异常时的恢复指引。

### v0.9.x：稳定性、测试、文档和试用反馈收敛

目标：为 v1.0.0 做发布候选准备。

应包含：

- 完整手动冒烟测试清单。
- 关键功能回归测试。
- README 和 docs 更新。
- 试用反馈整理。
- 明确 v1.0.0 不做事项。

### v1.0.0：正式单机版

发布定义：

> 一个无需账号、无需同步、可以长期本地使用的个人效率工具正式版。

发布前必须确认：

- 核心数据可靠。
- 备份和导入导出可用。
- 主要功能经过连续自用验证。
- 关键错误有可理解的提示。
- 文档能帮助未来继续维护。

### v1.1.x：账号与多端同步

v1.1.x 开始处理账号、同步和多设备一致性问题。

### v1.2.x：系统级提醒与通知

提醒功能放到正式版之后，并基于安卓端/桌面端/同步能力重新设计。

目标：

- DDL 临近提醒。
- 计划日程临近提醒。
- 每日自律提醒。
- 安卓和桌面系统通知。

## 暂缓事项

- v1.0.0 前不做账号和多设备同步。
- v1.0.0 前不做系统级提醒。
- AI 直接越过用户确认创建或修改日程。
- 通用脚本市场。
- 自动签到、刷课、答题、提交等学校系统写操作。
