## 数据与敏感信息边界

- Android 仅使用设备内 SQLite，不连接桌面 FastAPI，不内嵌 Python/FastAPI。
- AI Key、ZJU 密码和 Pintia Cookie 进入 AndroidKeyStore 支持的安全存储，不进入普通 SQLite、日志或 JSON 备份。
- 原生 Cookie 仅保存在进程内存；Capacitor 原生日志已关闭。
- Android 旧版备份和 Android 12+ data extraction 均排除数据库、偏好、文件和外部目录；FileProvider 仅共享应用缓存。
- 原生网络坚持 HTTPS、系统证书与 hostname 校验，不允许降级到 HTTP。
- 备份恢复在事务中执行；完整恢复前生成安全备份并读回校验。

## 已知外部限制

Celechron 校历上游当前 HTTPS 握手不可用，而 Android 明确禁止明文降级。因此 `/zju/calendar/fetch` 返回 `ZJU_CALENDAR_SECURE_TRANSPORT_UNAVAILABLE`；精确缓存仍可读取。只有上游恢复 HTTPS，或项目正式替换为可信 HTTPS 校历源后，才能完成实时校历验收。

## 正式完成条件

只有下列条件全部满足，才可把 v0.8 标记为完成：两台实体设备矩阵通过；真实文件和 ZJU 只读流程通过；用户本地配置 release 私钥并成功构建；APK 签名与 SHA-256 已记录；已知限制与实测结果回填本文件。账号、云同步、后台同步队列、系统级提醒和 ZJU 写操作不属于 v0.8。
